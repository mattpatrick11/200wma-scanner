# 📈 200-Week Moving Average Stock Scanner

A DIY investor dashboard tracking ~87 high-quality stocks across Large, Mid, and Small Cap tiers — ranked by proximity to their **200-week moving average**.

**Strategy:** *"If all you ever did was buy high-quality stocks on the 200-week moving average, you would beat the S&P 500 by a large margin over time. The problem is, few human beings have that kind of discipline."*

## Categories

| Category | Description |
|----------|-------------|
| 🔴 Deep Value | >10% below 200-WMA — rare entry points |
| 🟠 Undervalued | 3–10% below 200-WMA — prime buy territory |
| 🟢 Buy Zone | Within ±3% of 200-WMA — ideal entry |
| 🟡 Watchlist | 3–15% above 200-WMA — wait for pullback |
| ⬜ Extended | >15% above 200-WMA — not yet |

Click any stock row to expand a **price chart** showing weekly closes vs the 200-WMA with ±5% and ±10% bands.
